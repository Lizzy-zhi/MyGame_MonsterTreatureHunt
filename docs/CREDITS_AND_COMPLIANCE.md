## Ethical and Social Considerations

The game is a lightweight single-player platformer and does not include online interaction, monetization, gambling systems, or manipulative progression loops.

The project is designed around:

- short play sessions
- clear objectives
- low-content-risk presentation

## Accessibility Considerations

Positive points:

- simple keyboard control scheme
- in-game help panel
- clear menu flow
- short English briefing prompts before each map
- text labels alongside key icons in the inventory
- readable map progression from easier to harder levels

Current limitations:

- no remappable controls
- no audio accessibility options
- no integrated audio assets yet
- no subtitles because the game currently has no spoken dialogue
- color-coded key progression may still be harder for some players, even though icon and text support helps

## Security and Privacy Considerations

- the game is local and single-player
- no user accounts
- no cloud saves
- no networking features
- no personal data collection

This means security and privacy risk is minimal in the current version.

## Recommended Disclosure in a Submission

If this project is submitted with a report or presentation, it is worth stating clearly that:

- Kenney assets were used deliberately to keep scope realistic
- the game is a coursework vertical slice, not a commercial release
- map-specific briefing prompts were added to improve first-time player onboarding
- accessibility and audio could be improved in a future version
